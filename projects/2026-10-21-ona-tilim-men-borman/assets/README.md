# Assets inventory — Ona tilim: Men borman

Barcha mavjud va yangi reference rasmlar, video kliplar, audio, loyiha fayllari va eksportlar shu mavzu bilan bog‘liq holda kataloglanadi.

## Tavsiya etilgan papka tuzilishi
- `images/references/` — aktyor reference'lari va vizual yo‘nalish.
- `images/generated/` — generatsiya qilingan kadrlar va key art.
- `video/source/` — original generatsiya qilingan kliplar.
- `video/master/` — yakuniy original master.
- `video/exports/` — platforma uchun alohida eksportlar.
- `audio/voice/` — alohida yozilgan dialoglar.
- `audio/music/` — original musiqa.
- `audio/sfx/` — sound effectlar.
- `project-files/` — montaj loyihasi va motion design fayllari.

## Katta video fayllar
Original videoni sifatini yo‘qotmasdan saqlang. Git LFS ishlatilsa, upload'dan oldin LFS tracking va storage/bandwidth kvotalarini tekshiring. Aks holda GitHub Release asset yoki tasdiqlangan tashqi storage ishlating va to‘g‘ridan-to‘g‘ri havolani shu inventarga kiriting. Oddiy Git history'ga katta videoni qo‘shmang. Upload bo‘lmagan faylni uploaded deb ko‘rsatmang.
